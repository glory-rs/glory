# Glory 0.8.1

Desktop applications using Wry can now mount native select controls and radio
groups. Controlled selects preserve selected option keys, option groups and
the original element during resets. Radio groups support checked state,
keyboard navigation, focus and form values.

Wry keeps native drag gestures available when a press starts on a button in a
draggable item. It also supports threshold drag previews and contextual
overlays. File readers can finish reading an existing selection after the
picker is disabled. The Salvo adapter uses Salvo 1.2.

The 16 Glory packages share version 0.8.1. Rust 1.95 remains the minimum
supported compiler.
