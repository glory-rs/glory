# Glory 0.7.1

This maintenance release brings Wry drag and context menu support to the Glory
0.7 series. Wry can start a drag after a six-pixel pointer movement, optionally
show a preview, and route the drop to the live observer under the pointer.

Wry also hosts nonmodal context-point layers with keyboard and pointer menu
events, viewport-aware placement, outside dismissal, and focus restoration.

Existing press capture settings keep their behavior. Exhaustive matches on
`DragCapture` must account for `Threshold` and `ThresholdPreview`. Rust 1.95 and the
coordinated Apace, Takia, and Wingy engine versions carry forward from 0.7.0.
