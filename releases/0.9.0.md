# Glory 0.9.0

The native host uses Apace 0.4, Takia 0.16 and Wingy 0.31.2. Applications
constructing Apace wheel events must specify the input source and gesture
phase. Native virtual lists, modal layers and selection panels exercise the
new trackpad scrolling behavior.

The Wry renderer adds desktop interaction support for structured widgets,
keyboard input, layers and plots. The Salvo adapter uses Salvo 1.2.1.
